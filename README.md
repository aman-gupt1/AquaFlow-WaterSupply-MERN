# AquaFlow - Water Supply Management System

AquaFlow is a full-stack MERN web application for online water supply and delivery management. Users can browse water products, add items to cart, place orders, and track deliveries. Admins can manage users, products, and orders through a dedicated dashboard.

---

## 🎯 Purpose

This project was developed for self-improvement and to gain practical understanding of backend development concepts in a Water Supply Management System.
It helped improve knowledge of server-side logic, API handling, database operations, and real-world backend workflows.

---

# Features

## User Features
- User Authentication (Login / Register)
- Browse Water Products
- Add to Cart
- Remove Cart Items
- Place Orders
- Order Tracking
- Responsive UI for Mobile & Desktop

## Admin Features
- Admin Dashboard
- Manage Users
- Block / Unblock Users
- Delete Users
- Manage Products
- Manage Orders
- Update Delivery Status
